# ฝึกพับกล่อง · TGAT2 มิติสัมพันธ์

เว็บฝึกโจทย์ "พับกล่อง" (แผ่นคลี่ลูกบาศก์) ของ TGAT2 ผู้เรียนดูแผ่นคลี่ เลือกลูกบาศก์ที่ถูกต้อง
แล้วเปิดโมเดล 3D ที่พับให้ดูจริง และหมุนเทียบกับทุกตัวเลือกได้
และมีบทเรียนทีละขั้น 3 สูตร (ห้องสี่ผนัง · ตัดไว · กลิ้งกล่อง) ที่อธิบายแต่ละขั้นด้วยภาพ 3 มิติ ก่อนลองกับโจทย์จริง

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm test       # ทดสอบเรขาคณิตการพับ + ตรวจไฟล์โจทย์ทุกไฟล์
pnpm typecheck
pnpm build
```

## Tech stack

| ส่วน | ใช้ | เหตุผล |
| --- | --- | --- |
| แอป | TanStack Start + Router, React 19, Tailwind CSS 4 | SSR, file routes, route-level code splitting |
| 3D | three.js ผ่าน `@react-three/fiber` + `@react-three/drei` (`CameraControls`) | แผ่นคลี่คือต้นไม้ของบานพับ — แต่ละหน้าเป็น `group` ซ้อนกันและหมุนรอบขอบของหน้าพ่อ จึงพับทั้งกล่องได้ด้วยค่าเดียว |
| แอนิเมชัน | `useFrame` + `MathUtils.damp` | ไม่ต้องใช้ GSAP / Framer Motion และไม่ re-render React ทุกเฟรม (`frameloop="demand"` วาดเฉพาะตอนมีการเคลื่อนไหว) |
| ภาพ 2D | SVG | แผ่นคลี่และลูกบาศก์ไอโซเมตริกคมชัดทุกขนาด เหมือนภาพในข้อสอบ |
| โจทย์ | JSON + Zod | ตรวจรูปแบบและ "พับจริง" เพื่อหาคำตอบตอนโหลด |

three.js ถูกแยกเป็น chunk ที่โหลดเฉพาะตอนเปิดมุมมอง 3D (`LazyFoldStage`) หน้าแรกจึงเบา

ความคืบหน้า (ข้อที่ทำถูก ความแม่นยำ กิจกรรม 7 วัน) เก็บเฉพาะในเบราว์เซอร์ของผู้เรียนผ่าน `localStorage`
และอ่านด้วย `useSyncExternalStore` — ฝั่ง server ไม่รู้ประวัติ หน้าจึงแสดง skeleton จนกว่าจะ hydrate

ธีมสว่าง/มืดตามการตั้งค่าของเครื่องจนกว่าผู้ใช้จะกดสลับ ค่าที่เลือกเก็บใน cookie `theme` เพื่อให้ server
render ธีมที่ถูกต้องตั้งแต่แรก (ไม่กะพริบ) สีพื้นฐานใช้ token ตามบทบาท (`bg-surface`, `text-ink`, `border-line` …)
ที่ประกาศใน `src/styles.css` ส่วนสีสถานะใช้ `toneStyles` — ไม่ควรใช้ `stone-*` / `white` ตรง ๆ ในคอมโพเนนต์

## เพิ่มโจทย์

สร้างไฟล์ใหม่ใน `src/content/questions/` ชื่อไฟล์คือทั้งลำดับและ URL (เช่น `07-my-question.json` → `/questions/07-my-question`)
แนะนำให้ร่างในหน้า **สร้างโจทย์** (`/lab`) ซึ่งแสดงผลและตรวจให้ทันที

```json
{
  "title": "แถบคู่กับสี่เหลี่ยมทึบ",
  "difficulty": "easy",
  "layout": ["A...", "BCDE", ".F.."],
  "faces": {
    "A": [
      { "type": "rect", "x": 0, "y": 29, "w": 100, "h": 11 },
      { "type": "rect", "x": 0, "y": 60, "w": 100, "h": 11 }
    ],
    "B": [{ "type": "rect", "x": 0, "y": 50, "w": 50, "h": 50, "fill": "none" }],
    "C": [{ "type": "rect", "x": 25, "y": 25, "w": 50, "h": 50 }]
  },
  "choices": [
    { "top": "A", "left": { "face": "B", "rotate": 90 }, "right": "C" },
    { "top": "A", "left": "B", "right": "C" }
  ],
  "explanation": "ข้อความอธิบายหลังตรวจคำตอบ"
}
```

- **`layout`** วาดแผ่นคลี่เป็นแถวตัวอักษร หนึ่งตัวต่อหนึ่งหน้า (`A–Z`, `0–9`) และ `.` คือช่องว่าง ต้องมี 6 หน้าที่พับเป็นลูกบาศก์ได้จริง
- **`faces`** ลวดลายของแต่ละหน้าในกรอบ 100×100 (มุมซ้ายบน = 0,0 มองจากด้านนอกกล่อง) หน้าที่ไม่ใส่คือหน้าว่าง
  รูปที่ใช้ได้: `rect {x,y,w,h}`, `circle {cx,cy,r}`, `polygon {points}`, `line {from,to}` และ `fill`: `"black"` (ค่าเริ่มต้น) / `"gray"` / `"none"`
- **`choices`** 2–5 ข้อ แต่ละข้อบอกหน้าที่เห็นด้าน `top`, `left`, `right` เป็น `"A"` หรือ `{ "face": "A", "rotate": 90 }` (องศาตามเข็มนาฬิกา)
  `rotate: 0` คือหน้าตั้งตรงเมื่อมองจากด้านนอก — ด้านบนวางเหมือนพับขึ้นมาจากหน้าด้านซ้าย
- **`ask`** `"possible"` (ค่าเริ่มต้น) ถามรูปที่พับได้ หรือ `"impossible"` ถามรูปที่พับไม่ได้
- **`difficulty`** `"easy"` / `"medium"` / `"hard"`, **`prompt`** (ไม่บังคับ) ใช้แทนคำถามเริ่มต้น

**ไม่ต้องระบุคำตอบ** ระบบพับแผ่นคลี่แล้วลองจับลูกบาศก์ทั้ง 24 แบบเพื่อดูว่าตัวเลือกไหนพับได้
โดยเทียบ "หน้าตา" ของลวดลาย (หน้าว่างใช้แทนกันได้ และลายที่สมมาตรเมื่อหมุนถือว่าเหมือนเดิม)
โจทย์ที่มีคำตอบไม่ใช่ 1 ข้อพอดีจะไม่ผ่าน `pnpm test` และโหลดไม่ขึ้น

## บทเรียน 3 สูตร

การ์ด "เริ่มฝึกทีละขั้น" ในหน้าแรกเปิดหน้าต่างเลือกวิธี (bottom sheet บนมือถือ) แล้วพาไปที่ `/learn/$methodId?step=n`
แต่ละขั้นมีภาพ 3 มิติที่เล่นเองเป็น "จังหวะ" (pose) และบางขั้นมีตัวเลือกให้ลองตัดเอง ขั้นสุดท้ายคือโจทย์จริงจากคลัง

เนื้อหาอยู่ใน `src/content/methods/` เขียนเป็น TypeScript โดยแต่ละขั้นมี `scene` = แผ่นคลี่ + ลำดับจังหวะ
จังหวะหนึ่งบอกแค่สิ่งที่เปลี่ยนจากจังหวะก่อน (ยกเว้น `note` ที่ต้องเขียนทุกจังหวะ)

```ts
scene: {
  ...CROSS,                                   // แผ่นคลี่จาก nets.ts (layout + faces + anchor)
  poses: [
    { note: 'สีเดียวกัน = คู่ตรงข้าม', opposite: [['B', 'D'], ['C', 'E']] },
    { note: 'กลิ้ง A ไปต่อกับ D', move: { face: 'A', from: 'C', onto: 'D' } },
    { note: 'พับเป็นกล่อง', fold: 1, view: { top: 'A', left: 'D', right: 'E' } },
  ],
}
```

- **`fold`** `1` พับทุกบานพับ หรือ `{ B: 1, D: 1 }` พับเฉพาะหน้าที่ระบุ (นับจาก `anchor` ที่อยู่กับที่)
- **`move`** ตัดหน้า `face` ออกจาก `from` แล้วไปต่อกับ `onto` ตามขอบที่ชนกันจริงเมื่อพับ (หน้าที่ห้อยอยู่ย้ายตามไปด้วย ลายหมุนตาม)
- **`view`** ถือกล่องให้เห็นหน้าเหล่านี้ด้านบน/ซ้าย/ขวา เหมือนรูปในตัวเลือก
- **`opposite`** / **`meet`** / **`paint`** / **`labels`** ระบายคู่ตรงข้าม, ขีดขอบที่ชนกัน, ระบายสีอิสระ, เขียนคำบนหน้า

ทุกข้อความเชิงเรขาคณิตถูกตรวจกับกล่องที่พับจริงตอนโหลด — คู่ที่ไม่ได้ตรงข้ามกัน ขอบที่ไม่ได้ชนกัน
มุมมองที่เป็นภาพสะท้อน หรือตัวเลือกตัวอย่างที่ `verdict` ไม่ตรงกับการพับจริง จะทำให้ `pnpm test` ไม่ผ่าน

## โครงสร้าง

```
src/cube/          โดเมน (ไม่มี React): geometry, art, การพับแผ่นคลี่ (net), การย้ายหน้าในแผ่นคลี่ (arrangement), การเทียบภาพ (view), schema ของโจทย์
src/lesson/        โดเมนของบทเรียน: scene (จังหวะภาพ 3 มิติที่ตรวจแล้ว) และ method (ขั้นตอน ตัวอย่าง โจทย์ฝึก)
src/content/       คลังโจทย์ JSON + ตัวโหลดที่ตรวจทุกไฟล์, methods/ เนื้อหาบทเรียน 3 สูตร
src/progress/      ประวัติการตอบ (localStorage) + สรุปความคืบหน้าสำหรับแดชบอร์ด
src/theme/         ค่าธีมที่ผู้ใช้เลือก (cookie อ่านได้ทั้ง server และ browser)
src/components/    layout/ (แถบเมนู), dashboard/ (การ์ดหน้าแรก), cube/ (SVG), fold-stage/ (three.js), quiz/ (หน้าทำโจทย์),
                   lesson-stage/ (three.js ของบทเรียน: พับ เลื่อน กลิ้ง), learn/ (หน้าต่างเลือกวิธีและหน้าบทเรียน)
src/routes/        / (แดชบอร์ด), /questions (คลังโจทย์), /questions/$questionId, /learn/$methodId, /lab
```
